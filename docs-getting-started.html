Установка, проверка, первый запуск.

1. Системные требования

  • Windows 10 (1909+) или Windows 11
  • 64-bit (x64)
  • ~100 МБ свободного места
  • Права Администратора для Full Scan

2. Скачивание

Перейдите на страницу Загрузки и скачайте PeachCheck.exe. Файл portable — установка не требуется.

3. Проверка SHA-256

В PowerShell выполните:

Get-FileHash .\PeachCheck.exe -Algorithm SHA256

Сравните результат с хешем, указанным на странице загрузки.

4. Запуск

Для максимальной глубины запускайте от имени Администратора:

Right Click → Run as administrator

5. Первый скан

  1. Нажмите Quick Scan для быстрой оценки.
  2. Дождитесь завершения всех модулей.
  3. Изучите карточки находок.
  4. При необходимости экспортируйте отчёт.
Совет: Для максимальной глубины используйте Full Scan. Он включает Prefetch, Amcache, BAM/DAM и другие исторические источники.
