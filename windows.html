Windows

Windows Forensics

Десятки источников доказательств в одном приложении. Без сторонних утилит и PowerShell-скриптов.

Основные источники

Каждый источник даёт свой срез активности системы. Вместе они создают полную картину.

Prefetch

Windows записывает запуски программ в папку C:\Windows\Prefetch. Показывает, что запускалось, когда и сколько раз.

Amcache

Инвентаризация исполняемых файлов. Помогает найти следы удалённых программ и их пути.

BAM / DAM

Background Activity Moderator хранит последние запущенные программы для каждого пользователя.

UserAssist

Список программ, запущенных из GUI, с количеством запусков и временем последнего запуска.

ShimCache

Application Compatibility Cache. Содержит следы запуска исполняемых файлов, даже если они уже удалены.

Jump Lists

Недавние документы и приложения, закреплённые в панели задач. Помогает восстановить контекст.

LNK

Ярлыки в Recent и на рабочем столе содержат пути к запускаемым файлам и их MAC-время.

Registry Persistence

Run keys, RunOnce, Winlogon, Services, Image File Execution Options, Active Setup и другие точки закрепления.

Recycle Bin

Информация об удалённых файлах: оригинальный путь, время удаления, размер.
