Отчёты & Экспорт

JSON, TXT и HTML для разных сценариев.

JSON

Структурированный машиночитаемый формат. Подходит для автоматической обработки, загрузки в базу данных или интеграции с другими инструментами.

TXT

Текстовый отчёт для быстрого чтения в любом редакторе. Содержит сводку, находки и evidence в плоском виде.

HTML

Standalone HTML-отчёт с таблицами, фильтрами и подсветкой. Можно открыть в браузере без интернета.

Структура отчёта

  • Summary: общее количество находок по категориям.
  • Findings: список обнаружений с confidence, severity и evidence.
  • Artifacts: исторические следы и дополнительные источники.
  • Info: легитимный софт и контекст.

Интерпретация

Не полагайтесь только на количество DETECTED. Всегда смотрите confidence и список evidence. Если один источник — это повод проверить вручную, но не основание для окончательного решения.
