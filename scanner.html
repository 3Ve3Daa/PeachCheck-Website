Сканер

Два режима для разных задач

Quick Scan — быстрая оценка. Full Scan — полный forensic-обзор Windows и Minecraft.

Quick Scan

Процессы, реестр, persistence, сервисы, автозагрузка, Minecraft-установки и JAR-анализ. Идеально для оперативной проверки.

  • 10–30 секунд
  • Запуск без прав администратора*
  • Ключевые источники доказательств

Full Scan

Всё из Quick Scan плюс Prefetch, Amcache, BAM/DAM, UserAssist, ShimCache, SRUM, Jump Lists, LNK, Recycle Bin и Event Logs.

  • Глубокий анализ
  • Требуются права администратора
  • Исторические артефакты

* Часть реестра и системных артефактов доступна только с правами администратора.

Модули

Что проверяет PeachCheck

Scanner.Processes

Запущенные процессы, родительско-дочерние связи, командные строки, Authenticode-подписи, SHA-256.

Scanner.Registry

Autorun, Run keys, Winlogon, Services, Image File Execution Options и другие точки persistence.

Scanner.Windows

Prefetch, Amcache, BAM/DAM, UserAssist, ShimCache, SRUM, Jump Lists, LNK, Recycle Bin, Event Logs.

Scanner.Minecraft

Поиск установок, JAR-анализ, логи, JVM-аргументы, Java-процессы, Fabric/Forge/NeoForge.

Scanner.Files

Поиск по файловой системе, известные пути читов, подозрительные имена и расширения.

Detection / Correlation

Объединяет находки из разных модулей, вычисляет confidence и severity.
