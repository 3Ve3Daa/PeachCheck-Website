Как PeachCheck анализирует Windows-источники.

Prefetch

Папка C:\Windows\Prefetch содержит файлы, которые Windows создаёт при запуске программ. PeachCheck извлекает имя исполняемого файла, путь, хеш и время последнего запуска.

Amcache

Amcache.hve ведёт инвентаризацию программ. Помогает найти следы удалённых исполняемых файлов и их исходные пути.

BAM / DAM

Background Activity Moderator хранит последние запущенные программы для каждого пользователя в реестре. Полезен для восстановления истории запусков.

UserAssist

Содержит программы, запущенные из GUI, с ROT13-кодированными именами. Даёт счётчик запусков и время последнего старта.

ShimCache

Application Compatibility Cache хранит следы запуска исполняемых файлов. Помогает обнаружить программы, которые уже удалены с диска.

Persistence

PeachCheck проверяет точки закрепления: Run / RunOnce, Winlogon, Services, Image File Execution Options, Active Setup, Task Scheduler, WMI Events, BITS Jobs.

Важно: Большинство этих источников доступны только с правами Администратора. Запускайте Full Scan от имени Администратора.
